Vanila Snake Game

This is a sleek, minimalist Snake game built using Python programming. You control a white snake navigating a dark grid to eat orange pellets, causing your score to increase and the snake to grow longer. It features smooth key-bound movement and automatic collision detection that ends the game if you hit a wall or your own tail.
